# Демо-сценарий для жюри (2–3 минуты)

**0:00–0:20 — проблема.** «Иностранный студент после приезда получает правила из нескольких источников. Даже внутри одного маршрута есть разные сроки: университетские и государственные. Ошибка — это возврат к документам и потеря времени.»

**0:20–0:40 — старт в MAX.** Открыть чат-бота, показать приветствие и кнопку запуска подключённого мини-приложения.

**0:40–1:15 — персонализация.** Ввести: въезд 01.09.2026, общежитие, пребывание >90 дней, не Беларусь, нужна виза; окончание визы и регистрации — 30.11.2026. Нажать «Построить маршрут».

**1:15–1:45 — ценность.** Показать отсортированные карточки: конкретное действие, дедлайн, источник, отметка выполнения. Открыть первоисточник прямо из карточки.

**1:45–2:10 — динамический сценарий.** В разделе «Событие» поставить 18.09.2026. Показать появление задачи обратиться после события в течение 1 рабочего дня.

**2:10–2:25 — MAX сверх минимального требования.** Нажать «Поделиться маршрутом в MAX» и показать системный экран sharing через MAX Bridge.

**2:25–2:45 — масштабирование.** «Ядро не меняется: rule engine, карточка задачи, дедлайн, источник. Переменная часть — вуз, регион, язык и локальные правила. Следующий пилот — другой вуз Санкт-Петербурга, затем другой регион.»

**2:45–3:00 — границы.** «Мы не имитируем Госуслуги/МВД и не выдаём модельный результат за официальное решение. MVP работает на проверенных правилах и показывает источник каждого шага.»
