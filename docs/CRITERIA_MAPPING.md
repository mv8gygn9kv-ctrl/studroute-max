# Карта соответствия критериям хакатона

## Продуктовая оценка — 40%

### Потенциал масштабирования — 35% продуктовой части
Пилот ограничен СПбГЭУ, но ядро не зависит от конкретного вуза: rule engine, модель источника, карточки задач, события, статусы, MAX UX. При переходе в другой вуз меняются правила, контакты, региональные источники, языки и интеграции. План: СПбГЭУ → 2–3 вуза Санкт-Петербурга → вуз другого региона.

### Пользовательская ценность — 25%
Узкий сегмент, конкретный результат и прозрачный следующий шаг. Отдельно показано, что правила уже существуют, а проблема — в их сопоставлении и расчёте зависимых дат. Валидация боли интервью пока остаётся обязательной задачей до финала.

### UX/UI — 20%
Основной путь полностью помещён в mini-app; чат оставлен для старта/справки. Есть RU/EN, статусы, обработка ошибок, сохранение прогресса, источник в каждой карточке, life-event recalculation.

### Обоснованность и целостность — 15%
Правила детерминированы, не используется LLM для критичных решений, нет фиктивной интеграции с государственными ИС, факты отделены от расчёта и гипотез.

### Презентация — 5%
Готова структура с техническим слайдом, As Is/To Be, метриками, архитектурой, масштабированием, пилотом и рисками.

## Техническая оценка — 60%

### Работоспособность и функции — 30%
Маршрут строится end-to-end; автоматические тесты проверяют ключевые ветки и зависимый дедлайн медпроцедур.

### Интеграция и обмен данными — 20%
MAX Bot API, webhook, MAX Bridge, server-side validation WebAppData. API задокументирован OpenAPI 3.1 и DATA-API.

### Стабильность и ошибки — 10%
Валидация входных данных, таймаут MAX API, retry на 429, обработка ошибок UI, отсутствие необходимости полного перезапуска после ошибки.

### Архитектура — 20%
Один небольшой Node.js service, отдельные modules API/rules/validation, source registry, статический frontend. Нет лишних runtime dependencies.

### Безопасность и данные — 10%
Секреты только в environment, HMAC launch validation, webhook secret, минимум пользовательских данных, отсутствие паспортов/меддокументов, нет секретов в репозитории.

### Документация — 10%
README, Dockerfile, compose, `.dockerignore`, `.env.example`, tests, OpenAPI, DATA-API, test data, demo script, deploy guide, known limitations.

### Платформенный бонус
MAX используется не только как оболочка: MAX Bridge открывает официальные ссылки и sharing; бот и mini-app разделяют роли в одном пользовательском пути. До сдачи стоит проверить, что эта механика удовлетворяет формулировке бонуса на реальном клиенте MAX.
